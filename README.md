# CherekaNet

Site institutionnel de CherekaNet Services.

## Positionnement
- ⚡ Tech & Infrastructures
- 💻 Solutions digitales
- 🎨 Communication
- 🎉 Événementiel
- 🧠 Conseil & Services

Le site est construit from scratch avec une priorité commerciale donnée à **Tech & Infrastructures**.

## Stack
Next.js + TypeScript + Tailwind CSS.

## Développement
```bash
npm install
npm run dev
```

Vérification TypeScript :
```bash
npm run lint
```

Build de production :
```bash
npm run build
```
